# User Stories

## Super Admin

### US-001: Manage Users
**As a** Super Admin  
**I want to** manage users  
**So that** I can control platform access.

#### Acceptance Criteria
- [x] Super Admin can view users
- [x] Super Admin can create users
- [x] Super Admin can edit users
- [x] Role permissions are enforced

### US-002: Manage Tenants
**As a** Super Admin  
**I want to** manage tenant onboarding and status  
**So that** I can keep the platform healthy.

#### Acceptance Criteria
- [x] Super Admin can view tenants
- [x] Super Admin can approve or update tenant status
- [x] Super Admin can access platform-level analytics

## Tenant Admin

### US-003: Manage Loan Operations
**As a** Tenant Admin  
**I want to** monitor applications, customers, and loans  
**So that** I can run my lending operations.

#### Acceptance Criteria
- [x] Tenant Admin can open the dashboard
- [x] Tenant Admin can review applications
- [x] Tenant Admin can view customers and loans
- [x] Tenant Admin can access tenant settings

## Relationship Manager

### US-004: Review Customer Cases
**As a** Relationship Manager  
**I want to** review applications and collections  
**So that** I can support customer accounts.

#### Acceptance Criteria
- [x] RM can access the dashboard
- [x] RM can review applications and collections
- [x] RM can view customer activity

## Customer

### US-005: Apply for a Loan
**As a** Customer  
**I want to** submit a loan application  
**So that** I can request financing.

#### Acceptance Criteria
- [x] Customer can access the application form
- [x] Customer can view available loan products
- [x] Customer can submit a new application
